# Emotional Mapping API Contract (v1.0.0)

Base URL: `/api/v1`  
Protocol: HTTPS / HTTP (local development)  
Authentication: HTTP Bearer JWT (`Authorization: Bearer <access_token>`)

---

## 1. Global Response Envelope & Error Format

Every error response generated by the backend strictly conforms to this JSON structure:

```json
{
  "error": {
    "code": "string_machine_readable_code",
    "message": "Human readable user-safe message.",
    "details": null
  }
}
```

### Standard Error Codes

| HTTP Status | Error Code | Description |
|---|---|---|
| `400` | `invalid_filter` / `insufficient_scene_data` | Invalid query parameters or insufficient scene description (<10 chars). |
| `401` | `missing_token` | No `Authorization: Bearer <token>` header was provided. |
| `401` | `invalid_token` | The access token is expired, revoked, or invalid. |
| `404` | `not_found` / `project_not_found` / `scene_not_found` | Resource does not exist OR belongs to another user (preventing ID enumeration). |
| `422` | `validation_error` | Request body or query parameters failed Pydantic schema validation. |
| `429` | `daily_limit_exceeded` | User has reached the 20 AI generations/day application limit (resets 00:00 UTC). |
| `502` | `ai_validation_error` | Gemini output failed schema parsing after 1 automated retry. |
| `503` | `ai_service_error` | Gemini API timed out, rate limit/quota reached, or upstream unavailable. |
| `500` | `internal_server_error` | Unhandled exception (stack traces are never exposed to clients). |

## 2. Authentication Endpoints

### `GET /api/v1/auth/me`
Verifies the Bearer token and returns the authenticated user's ID and email.

- **Headers:** `Authorization: Bearer <token>`
- **Response `200 OK`:**
```json
{
  "id": "11111111-2222-3333-4444-555555555555",
  "email": "filmmaker@example.com"
}
```

## 4. Projects Endpoints

All project endpoints require authentication and enforce strict user data isolation.

### `POST /api/v1/projects`
Create a new project.

- **Request Body:**
```json
{
  "name": "The Desert Crossing",
  "type": "shot_design",
  "description": "An existential indie neo-western."
}
```
- **Response `201 Created`:**
```json
{
  "id": "uuid",
  "user_id": "uuid",
  "name": "The Desert Crossing",
  "type": "shot_design",
  "description": "An existential indie neo-western.",
  "created_at": "2026-10-17T12:00:00Z",
  "updated_at": "2026-10-17T12:00:00Z",
  "scenes": null
}
```

### `GET /api/v1/projects`
List projects owned by the authenticated user.

- **Query Parameters:**
  - `limit`: integer (1-100, default `50`)
  - `offset`: integer (>= 0, default `0`)
- **Response `200 OK`:**
```json
{
  "items": [...],
  "total": 1,
  "limit": 50,
  "offset": 0
}
```

### `GET /api/v1/projects/{project_id}`
Retrieve a project and its associated scenes.

- **Response `200 OK`:** `ProjectResponse` object (with `scenes` array).
- **Response `404 Not Found`:** If project does not exist or belongs to another user.

### `PATCH /api/v1/projects/{project_id}`
Update project title and/or description.

- **Request Body:**
```json
{
  "name": "Updated Title",
  "description": "Updated narrative notes"
}
```

### `DELETE /api/v1/projects/{project_id}`
Delete a project and cascade delete all its scenes and shot recommendations.

- **Response `204 No Content`**

## 5. Scenes Endpoints

### `POST /api/v1/scenes`
Create a scene under an owned project.

- **Request Body:**
```json
{
  "project_id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "description": "The protagonist sits at the rain-streaked diner booth watching the door.",
  "target_emotion": "isolation",
  "character_focus": "neutral_observer",
  "production_budget": "low",
  "budget_notes": "Single room interior, neon sign spill from outside."
}
```
- **Response `201 Created`:**
```json
{
  "id": 1,
  "project_id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "description": "The protagonist sits at the rain-streaked diner booth watching the door.",
  "target_emotion": "isolation",
  "character_focus": "neutral_observer",
  "production_budget": "low",
  "budget_notes": "Single room interior, neon sign spill from outside.",
  "video_url": null,
  "video_analysis": null,
  "experiment_group_id": null,
  "variant_label": null,
  "created_at": "2026-10-23T12:00:00Z",
  "shot_recommendations": null
}
```
- **Response `404 Not Found`:** If `project_id` does not exist or belongs to another user.

### `GET /api/v1/scenes/{scene_id}`
Retrieve a scene and its recommendations.

- **Response `200 OK`:** `SceneResponse` object (with populated `shot_recommendations`).

### `PATCH /api/v1/scenes/{scene_id}`
Update scene description, emotion, character focus, or budget.

### `DELETE /api/v1/scenes/{scene_id}`
Delete a scene and its recommendations.

- **Response `204 No Content`**

### `GET /api/v1/scenes/{scene_id}/recommendations`
Retrieve all existing saved shot recommendations for an authorized scene.

- **Response `200 OK`:** Array of `ShotRecommendationResponse` objects.

## 6. Shot Designer AI Generation

### `POST /api/v1/scenes/design-shots`
Invokes the Gemini AI pipeline to generate 4–5 distinct cinematography recommendations for the scene, replacing any previous recommendations atomically.

- **Request Body:**
```json
{
  "scene_id": 1
}
```

- **Response `200 OK`:**
```json
{
  "scene_id": 1,
  "model_used": "gemini-2.0-flash",
  "recommendations": [
    {
      "id": 1,
      "scene_id": 1,
      "rank": 1,
      "perspective_name": "Intimate High-Angle POV",
      "reasoning": "Elevating the camera slightly above eye level compresses the character into the booth corner, creating visual helplessness while maintaining empathy.",
      "visual_checklist": [
        "50mm prime lens at T2.0 for shallow depth of field",
        "Camera mounted on high tripod tilted 25 degrees down",
        "Reflections of rain on glass placed in foreground edge of frame",
        "Diffused overhead warm practical light with cool ambient fill"
      ],
      "context_caveat": "Excessive downward tilt will transform sympathetic isolation into clinical detachment.",
      "production_complexity_level": "Low",
      "production_complexity_reason": "Achievable with a standard tripod and single camera operator.",
      "budget_fit": "good_fit",
      "budget_fit_reason": "No specialized cranes or dollies needed; ideal for low-budget productions.",
      "knowledge_base_ids": [1],
      "model_name": "gemini-2.0-flash",
      "created_at": "2026-10-17T12:30:00Z"
    }
  ]
}
```

- **Error Responses:**
  - `400`: `{"error": {"code": "insufficient_scene_data", "message": "Scene description must be at least 10 characters."}}`
  - `404`: `{"error": {"code": "scene_not_found", "message": "Scene not found or access denied."}}`
  - `429`: `{"error": {"code": "daily_limit_exceeded", "message": "Daily AI generation limit reached (20 runs/day). Limit resets at 00:00 UTC."}}`
  - `502`: `{"error": {"code": "ai_validation_error", "message": "The AI response could not be validated against the expected format. Please try again."}}`
  - `503`: `{"error": {"code": "ai_service_error", "message": "AI rate limit or quota exceeded. Please try again later."}}`

## 7. Knowledge Base Endpoints

### `GET /api/v1/knowledge-base`
Browse cinematography techniques.

- **Query Parameters:**
  - `category`: `angle` | `shot_type` | `framing` | `movement` | `distance`
  - `emotion`: any controlled emotion string (e.g. `empathy`, `tension`)
  - `review_status`: `draft` | `reviewed`
  - `limit`: integer (1-100, default `50`)
  - `offset`: integer (>= 0, default `0`)

- **Response `200 OK`:**
```json
{
  "items": [
    {
      "id": 1,
      "technique_name": "Low Angle",
      "category": "angle",
      "visual_characteristic": "Camera positioned below subject eye line...",
      "potential_emotions": ["power", "tension", "blame"],
      "context_note": "Can convey heroism in one context and menace in another...",
      "example_scene": "An authority figure standing over a seated character.",
      "equipment_needs": "Standard camera or tripod positioned at or near ground level.",
      "typical_complexity": "Low",
      "review_status": "draft",
      "source_note": "Cinematography Theory & Practice 3rd Ed.",
      "created_at": "2026-10-17T12:00:00Z"
    }
  ],
  "total": 20,
  "limit": 50,
  "offset": 0
}
```

### `GET /api/v1/knowledge-base/{kb_id}`
Retrieve a single cinematography technique by integer ID.

- **Response `200 OK`:** `KnowledgeBaseResponse` object.
- **Response `404 Not Found`:** If technique ID does not exist.
